# homebrew-tap

[Homebrew](https://brew.sh) formulae for software by [@fralken](https://github.com/fralken).

## Formulae

| Formula | Description |
|---|---|
| [gatir](https://github.com/fralken/gatir) | Authenticating proxy for corporate proxies (NTLM, Kerberos) |

## Installation

```sh
brew tap fralken/tap
brew install <formula>
```

or in one step:

```sh
brew install fralken/tap/<formula>
```

`brew info <formula>` shows what a formula installs and any steps to take after
installing it.

To update:

```sh
brew update
brew upgrade <formula>
```

## About this repository

The formulae are in [`Formula`](Formula). Each one installs a prebuilt binary
from the matching release of its project, and checks it against the SHA-256
recorded in the formula. Some formulae are generated by the release of their
project, so they are not edited by hand: look at the project for the script.

These formulae are for macOS. For other systems, use the packages and archives
published with each release of the project.
